# Meus Gastos

App simples para controlar gastos. Funciona como aplicativo no celular (Android), sem internet, e os dados ficam **só no seu aparelho**.

## Como lançar um gasto
Digite valor + o que foi e toque em **Salvar**:

- `45 mercado`
- `23,50 uber`
- `ontem 120 farmácia`
- `05/11 80 gasolina`

O app escolhe a categoria sozinho. Se errar, toque na categoria certa antes de salvar.

## Abas
- **➕ Lançar**: registrar gasto e ver o total de hoje.
- **📊 Painel**: quanto ainda pode gastar no mês, gasto por categoria e últimos gastos.
- **⚙️ Ajustes**: limite do mês, colar vários gastos de uma vez e backup.

## Lançar pelo chat com o Claude
Mande os gastos no chat. O Claude devolve uma lista (um por linha). Copie, vá em **⚙️ Ajustes → Colar vários gastos** e toque em **Adicionar todos**.

## Instalar no Android
1. Abra o link do app no Chrome.
2. Toque nos 3 pontinhos (⋮) → **Adicionar à tela inicial** → **Instalar**.
3. Pronto: abre pelo ícone, em tela cheia, como um app.

## Backup
Os dados ficam só no celular. Uma vez por mês, vá em **⚙️ Ajustes → Baixar backup**.
